Статус «Транзит завершен»

Краткое описание изменений для разработчиков Альты

Коммит 0f38d06 POST /api/amocrm/td-status Без нового endpoint

Что изменилось

  • Существующий /td-status теперь принимает второй статус: Транзит завершен.
  • Запрос по-прежнему использует tdNum. Поле pdNum относится к отдельному /dt-status.
  • В amoCRM заполняются «Статус ТД» значением Транзит завершен и дата завершения в поле ID 990795.
  • Значение списка передаётся точным текстом, без enum ID. В amoCRM такой вариант списка уже должен существовать.
  • В основной воронке карточка не перемещается. Номер ТД и дата регистрации ТД не изменяются.
Новые воронки «Транзит по РФ» и «Офис МСК» в этот коммит не входят. Логика /dt-status не изменялась.

Запрос на завершение транзита

Заголовки: Content-Type: application/json и действующий Authorization: Bearer ….

{
  "vinNum": "LSGXC8356MV107322",
  "tdNum": "10716060/170726/TD000001",
  "status": "Транзит завершен",
  "statusDate": "2026-07-17 12:24:26"
}

Успешный HTTP-ответ:

HTTP 200
{
  "message": "OK"
}

Формат даты: Y-m-d H:i:s. Сохраняется действующая коррекция времени UTC+10 → UTC.
